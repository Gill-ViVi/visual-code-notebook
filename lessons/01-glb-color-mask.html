这一层只解决一个问题：为什么整个 GLB 直接改色容易出错，而分区换色能保护花盆和绿叶？

01 / THE PROBLEM · 遇到的问题

精致花箱，为什么不能直接跟着小屋换色？

原来 JavaScript 生成的小花会跟着整屋换色。后来我们用 Tripo 做出更精致的 GLB 花箱，却发现：如果直接修改共用材质，花瓣、绿叶和花盆可能一起受到影响。

02 / TRY IT · 同一盆花，两种换色方式

先选择「错误：整盆受影响」，连续切换三套配色；然后选择「正确：局部换色」。观察叶片和花盆有没有一起改变颜色。

教学示意：真实 GLB 整体染色并不一定变成同一种颜色，还可能因为原贴图相乘出现暗沉、偏色或串色。

03 / UNDERSTAND · 用一句话解释

Color Mask 就像 Photoshop 里的选区

如果没有选区，调整颜色可能影响整张图；先圈出花瓣，再调整颜色，就能保护绿叶和花盆。

不是给整盆花上色，而是先圈出花瓣，再只改花瓣。

这里先不用学遮罩的制作方法，也不用背 Shader 代码。第二层会拆开解释。

REMEMBER / 四个概念

GLB：存放3D几何、UV、材质和贴图等数据的文件格式。

UV：让3D表面的位置对应到2D贴图的位置。

Color Mask：标记哪些表面区域参与换色。

Shader：利用贴图、遮罩和配色，计算像素最终的显示效果。

UV 负责「在哪里」，Mask 负责「改不改」，Shader 负责「怎么画」。

Mask=0 表示保留原色，Mask=1 表示完全参与目标色处理。真实项目可能使用多通道遮罩和更复杂的色彩重映射。

EXTENSION / 拓展理解

什么时候不需要 Color Mask？

我们用遮罩，是因为原始 Tripo 花箱的花瓣、绿叶、花盆共用一个网格与一套材质。直接改整个材质的 Base Color，会连其他区域也一起影响。

展开：如果模型能分部件，直接改 Albedo 不就可以了吗？

可以，但关键是能否独立控制材质，而不只是分成多个 Mesh。 如果花瓣拥有独立材质，修改花瓣材质的 Base Color 就可以；一个 Mesh 也能有多个材质区域。反过来，即使拆成多个 Mesh，只要仍共享同一个材质对象，改它的颜色仍可能影响所有共享者。

如果花瓣、叶片和花盆共用一套材质与复杂颜色贴图，Color Mask 就适合在同一材质里划出允许换色的区域。

记住：Albedo / Base Color 说明“基础颜色是什么”；Color Mask 帮助判断“哪里可以改”。两者可以一起使用，并不是二选一。

有彩色 Base Color 贴图时，直接设置 material.color 通常会与贴图颜色相乘，未必得到指定纯色。换色前先检查网格、材质数量、是否共享材质及贴图结构。
