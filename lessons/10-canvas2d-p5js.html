一朵花，理解三种技术 🌷

JavaScript、Canvas 2D、p5.js 到底有什么关系？通过逐帧对照和可调节的小实验，理解“画笔、绘图库、编程逻辑”。

交互学习 · 可离线打开 · 约 10 分钟复习

01 / 先分清它们是谁

它们不是三种互相竞争的语言，而是不同层级的工具。

JavaScript编程语言：循环、变量、交互、动画逻辑
↓ 调用
p5.js用 JavaScript 编写的创意编程库：简化绘图与动画
↓ 普通 2D 模式通常使用
Canvas 2D API浏览器提供的原生 2D 绘图接口

🔎 注意：JavaScript 也可以直接操作 Canvas 2D，不必经过 p5.js；p5.js 还支持 WebGL 等其他渲染模式。

03 / 遇到没封装的图形呢？

画一个不规则花瓣：两种方法都需要自己指定曲线形状。

Canvas 2D
ctx.beginPath();
ctx.moveTo(150, 210);
ctx.bezierCurveTo(58,150,77,50,151,18);
ctx.bezierCurveTo(230,63,248,145,150,210);
ctx.fill();
p5.js
beginShape();
vertex(150, 210);
bezierVertex(58,150,77,50,151,18);
bezierVertex(230,63,248,145,150,210);
endShape(CLOSE);

✅ 没有现成的“花瓣函数”时，p5.js 也要定义花瓣。但可以借助贝塞尔曲线、循环或公式，无须一笔笔画出每个像素。

04 / 改参数，让程序自己画

你只需要定义一片花瓣的规则，让 JavaScript 循环重复它。试试滑块。

实验使用原生 Canvas 2D 实际绘制。p5.js 写法可使用同样的循环，替换成 ellipse()、rotate() 等函数。


05 / 最后理解“动画”
动画并不一定是视频文件，而是不断计算新位置，然后重新绘制画面。
Canvas 2D 的典型循环
function drawFrame() {
  ctx.clearRect(0,0,360,240);
  updatePetalPosition();
  drawPetal();
  requestAnimationFrame(drawFrame);
}
p5.js 的常见写法
function draw() {
  background(250);
  updatePetalPosition();
  drawPetal();
}
p5.js 会管理常用的 draw() 循环；Canvas 2D 通常自行组织帧更新。两者都需要你决定花瓣怎样运动。

留给未来的自己
一句话总结：JavaScript 决定“做什么、怎么变化”；Canvas 2D 是浏览器原生的 2D 画笔；p5.js 则提供更简洁、更适合创意实验的绘图与动画工具。
